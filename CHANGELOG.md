# Changelog

## 0.1.0 — 2026-10-20

- Add the versioned public CLI, help, diagnostics, Bash completion, named options,
  project-directory discovery, structured metadata output and usage errors.
- Preserve positional execution commands and their existing container boundaries.
- Add an offline Debian package, explicit per-user setup, previous-launcher backup
  and standard system paths. The engine remains the existing immutable image.
- Keep project declarations, state and credentials outside software installation.

Version numbers follow the policy in [the CLI contract](docs/debian-package.md).
